# 🎓 Платформа командообразования (Team Formation Platform)

**Выпускная квалификационная работа (ВКР)**

## 📖 О проекте

Веб-платформа для автоматизации распределения задач в проектных командах с использованием алгоритмов интеллектуального планирования.

**Проблема:** В студенческих и рабочих проектах задачи часто распределяются хаотично, что ведет к неравномерной нагрузке, срыву дедлайнов и «выгоранию» участников.

**Решение:** Платформа автоматически предлагает оптимальное распределение задач на основе навыков участников, их доступного времени и приоритета задач.

## 🎯 Цель и задачи

**Цель:** Разработать веб-платформу для автоматизированного распределения задач в проектных командах.

**Задачи:**
1. Проанализировать существующие решения (Trello, Jira, Asana) и выявить их ограничения.
2. Спроектировать архитектуру веб-приложения и структуру базы данных.
3. Разработать алгоритм распределения задач на основе многокритериальной оценки.
4. Реализовать серверную часть (бэкенд) и интерфейс пользователя (фронтенд).
5. Провести тестирование алгоритма на тестовых данных.

## 🧠 Алгоритм распределения

Алгоритм работает по принципу **многокритериальной оценки**. Для каждой пары «задача — исполнитель» вычисляется коэффициент соответствия:

```
Score = w1 * SkillMatch + w2 * TimeAvailability + w3 * PriorityWeight
```

Где:
- **SkillMatch** — соответствие навыков участника требованиям задачи.
- **TimeAvailability** — отношение свободного времени к требуемому.
- **PriorityWeight** — приоритет задачи.
- **w1, w2, w3** — весовые коэффициенты (настраиваются).

**Пример работы:**

| Задача | Требуемые навыки | Исполнитель | Свободное время | Рекомендация |
|--------|------------------|-------------|-----------------|--------------|
